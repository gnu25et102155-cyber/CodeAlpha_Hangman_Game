# Hangman Game

## 📌 Internship Task 1

A simple text-based Hangman game developed using Python. The player tries to guess a randomly selected word one letter at a time.

## 🎯 Objective

The objective of the game is to guess the hidden word before using all 6 incorrect guesses.

## 🚀 Features

- Contains 5 predefined words
- Randomly selects one word
- Allows the player to guess one letter at a time
- Displays correctly guessed letters
- Tracks incorrect guesses
- Allows a maximum of 6 incorrect guesses
- Displays the correct word when the player loses
- Displays a congratulations message when the player wins
- Runs completely in the console

## 🛠️ Technologies Used

- Python
- `random` module
- Lists
- Strings
- `while` loop
- `for` loop
- `if-else` statements
- User input
- Basic validation
